# Участие в разработке sponsrdump

## Сообщить о проблеме

Если вы заметили странности в поведении приложения или хотите предложить новую функциональность — смело заводите issue.

## Написать код

Если вы хотите поучаствовать в разработке: форкните, напишите код и пришлите запрос на слияние (pull request).

При написании кода придерживайтесь правил из [IDLE.md](https://github.com/idlesign/sponsrdump/blob/master/IDLE.md).

## Рабочий процесс

Задачи разработки обеспечивает [makeapp](https://pypi.org/project/makeapp/). Сначала поставьте или обновите его:

```shell
$ uv tool install makeapp
# или: uv tool upgrade makeapp
```

Затем из директории проекта:

```shell
# ставим утилиты
$ ma tools

# инициализируем виртуальное окружение
$ ma up --tool

# запускаем тесты
$ ma tests

# проверяем стиль перед отправкой кода на обзор
$ ma style
```
